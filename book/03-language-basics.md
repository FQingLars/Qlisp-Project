# Глава 3. Основы языка

## 3.1 S-выражения: главный синтаксис

В QLISP одна форма записи для всего — S-выражения (символьные выражения):

```lisp
(+ 1 2)            ; вызов: оператор первый, 1 + 2
(* (+ 1 2) 3)      ; вложенность вместо приоритетов: (1+2)*3
(print "hi")       ; вызов функции
```

> 🐍 **Python-аналогия.** `(+ 1 2)` — это `1 + 2`, а `(* (+ 1 2) 3)` — `(1 + 2) * 3`. Скобки заменяют и приоритеты операторов, и круглые скобки вызовов: `f(x, y)` → `(f x y)`.

Комментарии: `;` до конца строки.

## 3.2 Типы данных

| Тип | Пример | Python-аналог |
|---|---|---|
| Целое (fixnum, int64) | `42`, `-7` | `int` |
| Вещественное (flonum, double) | `3.14`, `1e-3` | `float` |
| Строка | `"hello"` | `str` |
| Символ | `x`, `MY-SYM` | — (ближе всего `enum`/интернированные имена) |
| Список (cons-ячейки) | `(1 2 3)`, `(1 . 2)` | `list` (односвязный) |
| nil | `nil` | `None` / `[]` |
| Истина | `t` | `True` |
| Тензор | `(tensor ((1.0) (2.0)))` | `np.ndarray` |
| Замыкание | `(lambda (x) (* x x))` | функция |

Символы регистронезависимы: ридер приводит их к верхнему регистру. Поэтому `Print`, `print` и `PRINT` — одно и то же.

Литеральные данные — через квотирование:

```lisp
'(1 2 3)          ; список-данные, не вызов
'foo              ; символ foo
`(a ,b ,@c)       ; квази-цитирование (шаблоны, гл. 12)
#'car             ; функция как значение
#(1 2 3)          ; вектор
#\A               ; символ-литера
```

> 🐍 В Python `'(1 2 3)` эквивалентен `[1, 2, 3]`, а `(1 . 2)` — паре `(1, 2)`.

## 3.3 Переменные: defvar, setq, let

```lisp
(defvar answer 42)        ; глобальная переменная
(setq answer 43)          ; изменить существующую

(let ((x 1) (y 2))        ; локальные биндинги (параллельные)
  (+ x y))                ; → 3

(let* ((x 1) (y (+ x 1))) ; последовательные биндинги
  y)                      ; → 2
```

> 🐍 **Python-аналогия.** `defvar` ≈ присваивание на верхнем уровне модуля; `setq` ≈ повторное присваивание; `let` ≈ локальные переменные функции — только с явной областью видимости в скобках:
> ```python
> x, y = 1, 2        # let  (параллельно)
> x = 1; y = x + 1   # let* (последовательно)
> ```

Разница `let`/`let*` — как в Python-распаковке `a, b = f(), g()` (обе вычисляются до присваивания) против трёх отдельных строк.

## 3.4 Функции: defun, lambda, \ 

```lisp
(defun add (a b) (+ a b))
(add 2 3)                        ; → 5

(defun greet (name &optional greeting)
  (strcat (if greeting greeting "Hello, ") name))
(greet "Lars")                   ; → "Hello, Lars"
(greet "Lars" "Привет, ")        ; → "Привет, Lars"
```

`&optional` — необязательные параметры, как значения по умолчанию в Python.

Анонимные функции:

```lisp
(lambda (x) (* x x))     ; полное имя
(\ (x) (* x x))          ; короткая форма — читается «лямбда»
(map (\ (x) (* x x)) '(1 2 3))   ; → (1 4 9)
```

> 🐍 `(\ (x) (* x x))` — это `lambda x: x * x`.

Вызов функции-значения: `(funcall f 5)` ≈ `f(5)`.

Рекурсия — естественный способ писать циклы (см. `length`, `reverse` в stdlib — все на рекурсии).

## 3.5 Списки

Список — односвязный список cons-ячеек. Базовые операции:

```lisp
(cons 1 '(2 3))     ; → (1 2 3)      — добавить в начало
(car '(1 2 3))      ; → 1            — голова
(cdr '(1 2 3))      ; → (2 3)        — хвост
(list 1 2 3)        ; → (1 2 3)      — создать из элементов
(append '(1 2) '(3))  ; → (1 2 3)    — конкатенация
(length '(1 2 3))   ; → 3
(reverse '(1 2 3))  ; → (3 2 1)
(nth 1 '(a b c))    ; → b            — элемент по индексу
(member 2 '(1 2 3)) ; → (2 3)        — поиск (возвращает хвост с позиции)
```

Комбинации `cadr`, `caddr`, `cddr` и т.д. — сокращения `(car (cdr x))`, как `x[1]`, `x[2]`, `x[2:]` в Python.

Функции высшего порядка:

```lisp
(map (\ (x) (* 2 x)) '(1 2 3))          ; → (2 4 6)
(filter (\ (x) (> x 1)) '(1 2 3))       ; → (2 3)
(reduce + '(1 2 3 4))                   ; → 10
(zip-with + '(1 2) '(10 20))            ; → (11 22)
```

> 🐍 **Python-аналогия.**
> ```python
> [2*x for x in xs]        # map
> [x for x in xs if x > 1] # filter
> functools.reduce(op.add, xs)  # reduce
> [a + b for a, b in zip(xs, ys)]  # zip-with
> ```

Важно: списки в QLISP иммутабельны по смыслу использования — операции создают новые списки (в scratch-памяти, гл. 5), нет `lst.append()`.

## 3.6 Управление потоком

```lisp
(if (> x 0) "pos" "neg")         ; if: (if условие then else)

(cond                            ; cond = цепочка elif
  ((< x 0) "neg")
  ((= x 0) "zero")
  (t "pos"))

(progn                           ; последовательность, значение последней
  (print "шаг 1")
  (print "шаг 2")
  (* 2 2))

(while (< i 10)                  ; цикл while
  (setq i (+ i 1)))

(and a b c)                      ; короткое замыкание
(or a b c)
```

> 🐍 `(if c a b)` — тернарник `a if c else b`. `(cond ...)` — `if/elif/else`. `(progn ...)` — тело функции. `and`/`or` — одноимённые операторы Python.

Любое значение кроме `nil` истинно. `nil` — одновременно «пустой список» и «ложь».

## 3.7 Сравнения и равенство

```lisp
(= 1 1)      (= 1.0 1.0)   ; числовое равенство
(string= "a" "a")          ; строки
(equal x y)                ; структурное равенство (любые типы) — как ==
(eq x y)                   ; идентичность — как is
(< <= > >=)                ; числа
```

> 🐍 `(equal a b)` — это `a == b`. `(= a b)` — только для чисел.

## 3.8 Арифметика и математика

```lisp
(+ 1 2 3)   (- 10 3)   (* 2 3 4)   (/ 7 2)
(mod 7 2)   (pow 2 10)  (sqrt 16.0) (abs -3)
(exp 1.0)   (log 2.718281)  (sin 0.0)  (cos 0.0)  (atan 1.0)
(random)    (randint 1 6)
(min2 1 2)  (max2 1 2)      ;; примитивы для двух аргументов
```

`(/ 7 2)` возвращает деление чисел QLISP-стилем; для целочисленного деления используйте `(/ (mod ...) ...)`-комбинации или работайте во float, как принято в ML-коде.

## 3.11 Собираем вместе: FizzBuzz

```lisp
(defun fizzbuzz (n)
  (cond
    ((= (mod n 15) 0) "FizzBuzz")
    ((= (mod n 3) 0)  "Fizz")
    ((= (mod n 5) 0)  "Buzz")
    (t (number-to-string n))))

(map fizzbuzz (range 16))
;; → (1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz)
```

> 🐍 Тот же код на Python:
> ```python
> def fizzbuzz(n):
>     if n % 15 == 0: return "FizzBuzz"
>     elif n % 3 == 0: return "Fizz"
>     elif n % 5 == 0: return "Buzz"
>     else: return str(n)
>
> [fizzbuzz(i) for i in range(1, 16)]
> ```

## 3.12 Тесты прямо в языке

В `core` встроен мини-фреймворк тестов:

```lisp
(deftest "fizzbuzz-15"
  (assert-eq (fizzbuzz 15) "FizzBuzz" "15 должно быть FizzBuzz"))

(run-tests)
```

`deftest` ≈ `def test_...()` в pytest, `run-tests` ≈ `pytest`.
